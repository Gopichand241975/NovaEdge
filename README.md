
# Test Repository:

## Purpose

This repository is used to **test new code before adding it to the Main Repository**.

Any new code, feature, modification, or experiment should first be added and tested here.

## Workflow

1. **Add the new code to this Test Repository.**
2. **Run and test the code.**
3. Check whether the code works correctly.
4. If there are errors, fix them and test again.
5. Continue testing until the code works as expected.
6. Once the code is confirmed to be working, move or copy the working code to the **Main Repository**.
7. The Main Repository should contain the **tested and working version**.

## Important Rule

**Test Repository → Test and Verify → Main Repository**

Do not directly add untested code to the Main Repository

## Main Purpose

The Test Repository provides a separate place for:

* Testing new code
* Trying new ideas
* Debugging errors
* Making experimental changes
* Verifying that the code works

Only after successful testing should the code be added to the Main Repository.
